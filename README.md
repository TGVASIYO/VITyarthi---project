# Expense & Budget Manager using python 
A simple Python-based project to record, manage, and analyze daily expenses using lists.

---

## 📌 Project Title
**Expense & Budget Manager Using Python Lists**

---

## 📌 Overview of the Project
This project is a menu-driven Expense Management System created using Python.  
It allows users to add, view, delete, and analyze expenses efficiently.  
All data is stored using Python lists, demonstrating how arrays can be used for real-life applications such as budgeting and financial tracking.

---

## 📌 Features
- ➕ **Add Expense**
- 📄 **View All Expenses**
- 💰 **Calculate Total Expense**
- 🗂️ **Category-wise Total**
- ❌ **Delete Expense (by index)**
- 🔍 **View Expense Details (by index)**
- 🚪 **Exit Program**

---

## 📌 Technologies / Tools Used
- **Python 3**
- **Lists (arrays)**
- Loops, Functions, Conditional Statements
- VS Code / Python IDLE / Terminal for execution
